# Model Comparisons

Use this file to track comparisons across models and providers.

## Comparison protocol

For each comparison, record:

- Model name and exact version or release date
- Platform/runtime and relevant settings
- Identical prompt and context, where possible
- Task and evaluation criteria
- Whether tools or web access were enabled
- Output quality, factual errors, latency, and cost where relevant
- Limitations and possible sources of bias

Avoid drawing broad conclusions from one prompt. Keep examples and scoring criteria so that comparisons can be revisited.
