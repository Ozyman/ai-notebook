# Reasoning and Hallucinations

## Questions

- What do we mean by a model “reasoning”?
- How can fluent answers be distinguished from reliable answers?
- Which tasks are prone to hallucination?
- When do browsing, citations, tools, or code execution improve reliability?
- How should uncertainty be communicated without overwhelming the answer?

## Evaluation ideas

Record concrete examples of correct and incorrect outputs, the conditions that produced them, and how correctness was checked.
