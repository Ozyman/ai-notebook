# Task-Specific Prompts

A place to collect reusable prompts for tasks that recur.

For each prompt, record:

- **Purpose:** What task it supports.
- **Prompt:** The reusable text.
- **Inputs:** What needs to be supplied.
- **Expected output:** What a useful result looks like.
- **Limitations:** Known failure modes or cases where it is unsuitable.
- **Last tested:** Date and model/platform, if relevant.

Avoid collecting prompts merely because they sound clever. Keep prompts that produce repeatably useful results.
